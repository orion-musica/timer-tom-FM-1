INSTALLER · M-VAVE FM-1

Install Timer Tom

Free, open-source kitchen timer firmware for the FM-1: four timers on four knobs and ambient sounds on the keys. Everything happens in your browser over USB-MIDI: no drivers, no apps. The original V15 firmware is built into the installer, so you can always go back.

BETA 0.1 · tested on hardware. Timer Tom has passed testing on an original M-VAVE FM-1 (FCC ID: 2ARCP-FM1). It is still a beta: you install it at your own risk. Back up first and keep the FM-1 powered and connected until the installer says it is done.

What you need

FM-1

Any M-VAVE FM-1, on stock V15 or an FM1 Open build. Charged or on USB power.

USB data cable

A cable that carries data, not just power. Plug it straight into the computer, not a hub.

Chrome or Edge

On Windows, macOS or Linux. Allow MIDI and SysEx when the browser asks.

Steps

About five minutes. The installer guides you, but here is the whole route.

  1. Back up

    Export the projects, voices and samples you want to keep. Keep a copy of the original FM-1.fwsc from M-VAVE's download page. Close DAWs and other MIDI apps.

  2. Connect

    Switch the FM-1 on, plug in the USB cable, press START INSTALLER, then Connect device. Allow MIDI / SysEx.

  3. First time from stock V15

    The installer sees FM-1_015. Click Enable force flash and reconnect. This only reconnects; nothing is written yet. Coming from FM1 Open? Skip this step.

  4. Install

    Tick the backup confirmation, click Force flash (or Install) and accept the warning. Do not unplug or switch off while it writes.

  5. Check samples and play

    Wait for the sample check to finish. If samples are not ready, restore the sample bank in Projects & sounds; do not flash again. The FM-1 restarts into the Timer Tom boot screen. The KITCHEN page with four empty timers opens.

Back to stock

Changed your mind? Open the installer and click Restore original V15. It installs the original firmware and restores all 128 factory voices across four banks.

Timer Tom projects and samples do not work on stock firmware. Export them first. To come back to Timer Tom later, use force flash again.

Help

The browser does not find the FM-1

Close other MIDI apps and installer tabs, switch the FM-1 off and on, reconnect USB and click Connect again. Open Connection details in the installer to see which MIDI ports the browser found.

START is greyed out

The ready check shows why. Wrong browser: use desktop Chrome or Edge (Safari, Firefox and phones have no Web MIDI). Opened as a file: run OPEN-SITE.bat so the page runs on localhost.

The update stopped halfway

Keep the cable in, power-cycle the FM-1, reconnect and run the installer again with force flash.

It says NOT BUILT

The firmware has to be compiled once. On Windows run INSTALL-TIMER-TOM.bat in the project folder. It builds Timer Tom and opens this page on http://localhost:8766.

Will I lose my projects?

An update with the same storage layout keeps valid project slots and the sample bank. Switching from stock V15 does not. Back up either way.
